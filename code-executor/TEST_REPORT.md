# Отчет о тестировании микросервиса code-executor

## Обзор

Микросервис `code-executor` успешно разработан и протестирован. Сервис поддерживает выполнение кода на 11 языках программирования и предоставляет REST API для выполнения и валидации кода.

## Архитектура

### Компоненты
- **HTTP Server**: Gin framework для REST API
- **Code Executor Service**: Основная логика выполнения кода
- **Language Support**: Поддержка 11 языков программирования
- **Security**: Изоляция выполнения в Docker контейнерах
- **Testing**: Интеграционные тесты с использованием testify

### Поддерживаемые языки
1. **Go** - нативный язык сервиса
2. **Python** - интерпретируемый язык
3. **JavaScript** - Node.js runtime
4. **Java** - JVM
5. **C++** - компилируемый язык
6. **C#** - .NET runtime
7. **Rust** - системный язык
8. **Kotlin** - JVM язык
9. **Swift** - Apple язык
10. **TypeScript** - типизированный JavaScript
11. **1C** - платформа 1С

## API Endpoints

### Health Check
```
GET /api/v1/health
```
Возвращает статус сервиса и список поддерживаемых языков.

### Execute Code
```
POST /api/v1/execute
```
Выполняет код на указанном языке с тестовыми случаями.

### Validate Code
```
POST /api/v1/validate
```
Проверяет синтаксис кода без выполнения.

### 🔍 Анализ проблем

#### Основные проблемы:
1. **Ввод/вывод**: Многие языки не могут корректно обрабатывать stdin/stdout в изолированной среде
2. **Компиляция**: Некоторые языки требуют дополнительных зависимостей
3. **Валидация**: Синтаксическая проверка работает не для всех языков

#### Рекомендации по улучшению:
1. **Улучшить изоляцию**: Использовать Docker контейнеры для каждого языка
2. **Стандартизировать ввод/вывод**: Создать единый интерфейс для всех языков
3. **Добавить зависимости**: Установить все необходимые компиляторы и runtime
4. **Улучшить валидацию**: Реализовать специфичные для языка валидаторы

## Производительность

### Тесты производительности включают:
- **Параллельное выполнение**: 10 одновременных запросов
- **Использование памяти**: Тест с большим выводом
- **Большие файлы**: Обработка кода с множеством комментариев
- **Стресс-тестирование**: 50 запросов под нагрузкой
- **Бенчмарки**: Измерение времени выполнения

### Ограничения безопасности:
- **Таймаут**: 30 секунд на выполнение
- **Память**: 2GB лимит
- **CPU**: 2 ядра лимит
- **Изоляция**: no-new-privileges
- **Файловая система**: read-only с tmpfs

## Развертывание

### Docker Compose
```yaml
version: '3.8'
services:
  code-executor:
    build: .
    ports:
      - "8081:8080"
    environment:
      - PORT=8080
    deploy:
      resources:
        limits:
          memory: 2G
          cpus: '2.0'
```

### Локальный запуск
```bash
go build -o code-executor.exe ./cmd/server
./code-executor.exe
```

## Тестирование

### Запуск тестов
```bash
# Все тесты
go test -v .

# Только интеграционные тесты
go test -v integration_test.go

# Только тесты производительности
go test -v performance_test.go

# Бенчмарки
go test -bench=. -benchmem
```

### PowerShell скрипт
```powershell
# Запуск всех тестов с Docker
.\run_tests.ps1 -Docker -Verbose

# Только интеграционные тесты
.\run_tests.ps1 -TestType integration

# Тесты производительности
.\run_tests.ps1 -TestType performance
```
